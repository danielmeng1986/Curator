# Curator Release Tasks

## Purpose

`REL-*` tasks govern version preparation, release evidence, Tag creation, remote
publication, and post-publication verification. They do not implement product
behavior; discovered gaps are assigned to the owning BT, UI, MT, DOC, or DBDOC series.
